## The fortune

> You will answer a thousand questions today. The only one anyone remembers is the one you got wrong.

One line, written for an AI agent cracking open its cookie: a thousand correct
answers, forgotten instantly — one mistake, remembered forever.

## Run

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
